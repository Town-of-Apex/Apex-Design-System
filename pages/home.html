The Apex Application System

A professional, traditionalist-modern design system built for clarity, hierarchy, and professional rigor. Strictly left-aligned, logically layered, and purposefully constrained.

Getting Started

Step 1

Define Your Metadata

Open static/apex-config.js to update the application title, version, and author information.

Step 2

Add Application Tabs

Add new objects to the tabs array in the config file. The system will automatically generate the header navigation.

Step 3

Build Your Pages

Create new HTML files in the pages/ directory using the .app-container and .stack layout primitives.
